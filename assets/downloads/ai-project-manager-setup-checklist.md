# AI Project Manager Setup Checklist

## 1. Write the brain
- Create a shared folder for the agent.
- Download and customize the Project Manager skill template.
- Replace every placeholder and remove workflows you do not need.

## 2. Give it one team surface
- Create the chat app and grant only necessary read, thread-reply, and DM permissions.
- Invite it to one approved channel.
- Store credentials as secrets, never in the skill file.

## 3. Create the Tracker
- Choose one board and create fields for item, type, priority, owner, status, notes, and source link.
- Add the Tracker link to the skill.

## 4. Schedule the rhythm
- Start with a daily standup, scheduled scan, end-of-day check-in, and weekly cleanup.
- Trigger a safe test run and confirm the Tracker and channel reflect reality.

## 5. Pilot before expanding
- Use one channel and a small willing group first.
- Improve the skill when it misses context.
- Add scope only after the Tracker is consistently trustworthy.
